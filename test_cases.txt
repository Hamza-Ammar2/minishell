================================================================================
                        MINISHELL TEST CASES
================================================================================

This file contains test cases to validate your minishell implementation.
Compare your output with bash behavior.


================================================================================
                            BASIC COMMANDS
================================================================================

Test 1: Simple command with no arguments
-----------------------------------------
Input:  pwd
Expected: Print current directory

Input:  ls
Expected: List files in current directory

Input:  date
Expected: Print current date and time


Test 2: Commands with arguments
--------------------------------
Input:  echo hello
Expected: hello

Input:  echo hello world
Expected: hello world

Input:  ls -la
Expected: Long format listing with hidden files

Input:  mkdir test_dir
Expected: Create directory named test_dir


Test 3: Commands with absolute/relative paths
----------------------------------------------
Input:  /bin/ls
Expected: List files (same as ls)

Input:  ./minishell
Expected: Run minishell from current directory (if executable exists)

Input:  ../other_dir/program
Expected: Run program from parent directory


================================================================================
                            BUILT-IN COMMANDS
================================================================================

Test 4: echo built-in
---------------------
Input:  echo hello
Expected: hello

Input:  echo "hello world"
Expected: hello world

Input:  echo -n hello
Expected: hello (no newline)

Input:  echo -n -n -n hello
Expected: hello (no newline, multiple -n flags)

Input:  echo $PATH
Expected: Value of PATH variable

Input:  echo "$USER is here"
Expected: [username] is here


Test 5: cd built-in
-------------------
Input:  cd /tmp
        pwd
Expected: /tmp

Input:  cd ..
        pwd
Expected: Parent directory

Input:  cd
        pwd
Expected: Home directory

Input:  cd ~
        pwd
Expected: Home directory

Input:  cd invalid_directory
Expected: Error message (directory doesn't exist)

Input:  cd /root (as non-root user)
Expected: Error message (permission denied)


Test 6: pwd built-in
--------------------
Input:  pwd
Expected: Current working directory path

Input:  cd /tmp
        pwd
Expected: /tmp


Test 7: export built-in
-----------------------
Input:  export TEST=hello
        echo $TEST
Expected: hello

Input:  export PATH=/custom/path
        echo $PATH
Expected: /custom/path

Input:  export VAR="hello world"
        echo $VAR
Expected: hello world

Input:  export EMPTY=
        echo $EMPTY
Expected: (empty line)


Test 8: unset built-in
----------------------
Input:  export TEST=hello
        echo $TEST
        unset TEST
        echo $TEST
Expected: hello
          (empty line)

Input:  unset PATH
        ls
Expected: Command not found (no PATH)


Test 9: env built-in
--------------------
Input:  env
Expected: List all environment variables

Input:  export CUSTOM=value
        env | grep CUSTOM
Expected: CUSTOM=value


Test 10: exit built-in
----------------------
Input:  exit
Expected: Shell exits with status 0

Input:  exit 42
Expected: Shell exits with status 42

Input:  exit 999
Expected: Shell exits with status 231 (999 % 256)

Input:  exit hello
Expected: Error message, exit with status 255


================================================================================
                            QUOTES AND ESCAPING
================================================================================

Test 11: Single quotes
----------------------
Input:  echo 'hello world'
Expected: hello world

Input:  echo '$PATH'
Expected: $PATH (literal, no expansion)

Input:  echo 'hello   world'
Expected: hello   world (preserve spaces)


Test 12: Double quotes
----------------------
Input:  echo "hello world"
Expected: hello world

Input:  echo "$PATH"
Expected: [PATH value] (expansion happens)

Input:  echo "hello   world"
Expected: hello   world (preserve spaces)


Test 13: Mixed quotes
---------------------
Input:  echo hello"world"
Expected: helloworld

Input:  echo "hello"'world'
Expected: helloworld

Input:  echo "hello '$USER'"
Expected: hello '$USER'

Input:  echo 'hello "$USER"'
Expected: hello "$USER"


Test 14: Empty quotes
---------------------
Input:  echo ""
Expected: (empty line)

Input:  echo ''
Expected: (empty line)

Input:  echo "" hello
Expected:  hello (space before hello)


================================================================================
                            ENVIRONMENT VARIABLES
================================================================================

Test 15: Variable expansion
---------------------------
Input:  echo $PATH
Expected: [PATH value]

Input:  echo $USER
Expected: [username]

Input:  echo $HOME
Expected: [home directory]

Input:  echo $UNDEFINED
Expected: (empty line)


Test 16: Exit status ($?)
--------------------------
Input:  ls
        echo $?
Expected: 0 (success)

Input:  ls nonexistent_file
        echo $?
Expected: Non-zero error code

Input:  false
        echo $?
Expected: 1

Input:  true
        echo $?
Expected: 0


Test 17: Variable expansion edge cases
---------------------------------------
Input:  echo $
Expected: $

Input:  echo $$
Expected: $$ (or PID, depending on implementation)

Input:  echo $?$?
Expected: 00 (if last command succeeded)

Input:  echo hello$USER
Expected: hello[username]

Input:  echo $USER$PATH
Expected: [username][PATH value]


================================================================================
                            REDIRECTIONS
================================================================================

Test 18: Output redirection (>)
-------------------------------
Input:  echo hello > file.txt
        cat file.txt
Expected: hello

Input:  ls > output.txt
        cat output.txt
Expected: [directory listing]

Input:  echo hello > file.txt
        echo world > file.txt
        cat file.txt
Expected: world (overwrite)


Test 19: Input redirection (<)
------------------------------
Prep:   echo "hello" > input.txt
Input:  cat < input.txt
Expected: hello

Input:  wc -l < input.txt
Expected: 1


Test 20: Append redirection (>>)
--------------------------------
Input:  echo hello > file.txt
        echo world >> file.txt
        cat file.txt
Expected: hello
          world


Test 21: Heredoc (<<)
---------------------
Input:  cat << EOF
        line 1
        line 2
        EOF
Expected: line 1
          line 2

Input:  cat << END > output.txt
        test
        END
        cat output.txt
Expected: test


Test 22: Multiple redirections
-------------------------------
Input:  echo hello > file1.txt > file2.txt
        cat file1.txt
        cat file2.txt
Expected: (empty)
          hello
          (last redirection wins)

Input:  < input.txt cat > output.txt
Expected: Contents of input.txt copied to output.txt


Test 23: Redirection errors
----------------------------
Input:  cat < nonexistent.txt
Expected: Error message (no such file)

Input:  echo hello > /root/file.txt (as non-root)
Expected: Error message (permission denied)


================================================================================
                            PIPES
================================================================================

Test 24: Simple pipes
---------------------
Input:  echo hello | cat
Expected: hello

Input:  ls | wc -l
Expected: Number of files/directories

Input:  echo "hello world" | wc -w
Expected: 2


Test 25: Multiple pipes
-----------------------
Input:  ls | grep test | wc -l
Expected: Number of items containing "test"

Input:  cat file.txt | grep pattern | sort | uniq
Expected: Unique sorted lines matching pattern

Input:  echo "a b c" | tr ' ' '\n' | sort
Expected: a
          b
          c


Test 26: Pipes with redirections
---------------------------------
Input:  cat < input.txt | grep test > output.txt
Expected: Lines containing "test" from input.txt saved to output.txt

Input:  echo hello | cat > file.txt
        cat file.txt
Expected: hello


Test 27: Pipes with built-ins
------------------------------
Input:  echo $PATH | cat
Expected: [PATH value]

Input:  export TEST=hello | cat
Expected: (nothing - export doesn't output)

Input:  env | grep USER
Expected: USER=[username]


================================================================================
                            SIGNAL HANDLING
================================================================================

Test 28: Ctrl+C (SIGINT)
------------------------
Action: Press Ctrl+C while waiting for input
Expected: Display new prompt, shell continues running

Action: Run "sleep 10", then press Ctrl+C
Expected: Sleep interrupted, return to prompt
          echo $?
Expected: 130


Test 29: Ctrl+D (EOF)
---------------------
Action: Press Ctrl+D while waiting for input
Expected: Shell exits (like "exit" command)

Action: Run "cat", then press Ctrl+D
Expected: cat terminates, return to prompt


Test 30: Ctrl+\ (SIGQUIT)
-------------------------
Action: Press Ctrl+\ while waiting for input
Expected: Nothing happens (signal ignored)

Action: Run "sleep 10", then press Ctrl+\
Expected: Sleep terminated with "Quit" message
          echo $?
Expected: 131
