WORD SPLITTING IMPLEMENTATION
=============================

WHAT IS WORD SPLITTING?
-----------------------
In bash, when a variable is expanded WITHOUT quotes, the result is split
on whitespace (IFS) into multiple words/arguments. This is called "word splitting."

Example:
  VAR="one two three"
  echo $VAR      -> echo receives 3 arguments: "one", "two", "three"
  echo "$VAR"    -> echo receives 1 argument: "one two three"


IMPLEMENTATION APPROACH: Tokenize -> Expand -> Re-tokenize
-----------------------------------------------------------
1. TOKENIZE: Break input into tokens (already implemented)
2. EXPAND: Replace $VAR with its value
3. RE-TOKENIZE (Word Split): For unquoted expansions, split on whitespace

KEY DESIGN DECISION
===================

The new approach BUILDS A NEW TOKEN LIST instead of modifying in place.
This is cleaner because:
- No complex pointer manipulation
- No tracking of prev/current/next with edge cases
- Simple iteration: process each token, append result to new list
- Original tokens are freed at the end

Old approach (complex):
  - Modify tokens in place
  - Track should_free flag
  - Complex prev/next pointer updates

New approach (simple):
  - Build new list from scratch
  - Each token -> expand -> split if needed -> append to result
  - Free original list at end
