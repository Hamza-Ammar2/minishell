================================================================================
                    MINISHELL SIMPLE FUNCTION TREE
================================================================================

1. main()
   WHY: Entry point of the program
   HOW: Calls init, loop, and cleanup in sequence
   
   ├─> init_shell()
   │   WHY: Set up initial shell state
   │   HOW: Sets exit_status to 0
   │
   ├─> shell_loop()
   │   WHY: Main interactive loop - keeps shell running
   │   HOW: Infinite loop that reads and processes input until exit
   │   │
   │   ├─> readline()
   │   │   WHY: Get user input with editing features
   │   │   HOW: Displays prompt, waits for input, returns malloc'd string
   │   │
   │   ├─> add_history()
   │   │   WHY: Enable up/down arrow navigation
   │   │   HOW: Saves input to readline's history buffer
   │   │
   │   └─> process_input()
   │       WHY: Convert input string into executable command
   │       HOW: Tokenize → Parse → Execute pipeline
   │       │
   │       ├─> tokenize()
   │       │   WHY: Break input into meaningful pieces (tokens)
   │       │   HOW: Loop through string, identify words, quotes, and operators
   │       │   │
   │       │   ├─> is_quote()
   │       │   │   WHY: Check if current char is a quote (' or ")
   │       │   │   HOW: Compare char with ASCII 34 (") and 39 ('), return bool
   │       │   │
   │       │   ├─> extract_quoted_word()
   │       │   │   WHY: Extract quoted strings as single tokens
   │       │   │   HOW: Find closing quote, extract substring with quotes, set quote_type
   │       │   │   │
   │       │   │   ├─> find_closing_quote()
   │       │   │   │   WHY: Locate matching closing quote
   │       │   │   │   HOW: Loop through string after opening quote, return index or -1
   │       │   │   │
   │       │   │   └─> ft_substr()
   │       │   │       WHY: Extract substring including both quotes
   │       │   │       HOW: Use libft to allocate and copy substring
   │       │   │
   │       │   ├─> is_operator()
   │       │   │   WHY: Check if current char is |, <, >, etc.
   │       │   │   HOW: Compare char with operator list, return operator string
   │       │   │
   │       │   ├─> process_operator()
   │       │   │   WHY: Handle operator tokens
   │       │   │   HOW: Create token with type and quote_type=0, add to list, return length
   │       │   │   │
   │       │   │   ├─> get_token_type()
   │       │   │   │   WHY: Convert operator string to enum type
   │       │   │   │   HOW: Compare operator, return TOKEN_PIPE/REDIRECT/etc
   │       │   │   │
   │       │   │   ├─> new_token()
   │       │   │   │   WHY: Allocate memory for new token node with quote info
   │       │   │   │   HOW: malloc token, set type/value/quote_type/next, return pointer
   │       │   │   │
   │       │   │   └─> add_token_to_list()
   │       │   │       WHY: Append token to end of linked list
   │       │   │       HOW: Traverse to last node, link new token
   │       │   │
   │       │   └─> process_word()
   │       │       WHY: Handle word tokens (commands/arguments)
   │       │       HOW: Extract word, create token with quote_type=0, add to list, return length
   │       │       │
   │       │       ├─> extract_word()
   │       │       │   WHY: Get word string from input (stops at quotes too)
   │       │       │   HOW: Count chars until space/operator/quote, malloc and copy
   │       │       │
   │       │       ├─> new_token()
   │       │       │   WHY: Create token node for the word
   │       │       │   HOW: malloc token, set type=TOKEN_WORD, strdup value, quote_type=0
   │       │       │
   │       │       └─> add_token_to_list()
   │       │           WHY: Add word token to list
   │       │           HOW: Traverse to end, link new token
   │       │
   │       ├─> parse()
   │       │   WHY: Convert token list into command structure
   │       │   HOW: Count args, allocate array, fill with values
   │       │   │
   │       │   ├─> new_command()
   │       │   │   WHY: Allocate memory for command structure
   │       │   │   HOW: malloc t_command, set args=NULL, return pointer
   │       │   │
   │       │   ├─> count_args()
   │       │   │   WHY: Determine how big args array needs to be
   │       │   │   HOW: Loop through TOKEN_WORD tokens, increment counter
   │       │   │
   │       │   └─> fill_args()
   │       │       WHY: Copy token values into args array
   │       │       HOW: Loop through tokens, strdup each value into args[i]
   │       │
   │       ├─> execute() [TODO - Hamza's part]
   │       │   WHY: Run the command
   │       │   HOW: Fork, execve, wait for process
   │       │
   │       ├─> free_commands()
   │       │   WHY: Prevent memory leaks
   │       │   HOW: Free each string in args, free args array, free cmd
   │       │
   │       └─> free_tokens()
   │           WHY: Clean up token list
   │           HOW: Traverse list, free value and node for each token
   │
   └─> cleanup_shell()
       WHY: Clean up before program exits
       HOW: Calls rl_clear_history() to free readline's memory


================================================================================
                        EXECUTION FLOW SUMMARY
================================================================================

User types: echo 'hello world'
     |
     v
1. readline() → Returns "echo 'hello world'" (malloc'd)
     |
     v
2. add_history() → Saves "echo 'hello world'" for arrow keys
     |
     v
3. tokenize() → Breaks into tokens (now handles quotes!)
     |
     ├─> is_quote('e') → No
     ├─> is_operator("echo...") → NULL (not operator)
     ├─> process_word("echo 'hello world'")
     │   ├─> extract_word() → "echo" (stops at quote)
     │   ├─> new_token(TOKEN_WORD, "echo", 0) → quote_type=0
     │   └─> add_token_to_list()
     │
     ├─> is_quote('\'') → Yes! 
     └─> extract_quoted_word("'hello world'...")
         ├─> find_closing_quote("hello world'...") → Returns 11
         ├─> ft_substr() → Extracts "'hello world'" (with quotes)
         ├─> new_token(TOKEN_WORD, "'hello world'", 1) → quote_type=1
         └─> add_token_to_list()
     |
     v
   Result: [TOKEN_WORD:"echo", quote_type=0] → [TOKEN_WORD:"'hello world'", quote_type=1] → NULL
     |
     v
4. parse() → Converts to command structure
     |
     ├─> new_command() → Allocates cmd
     ├─> count_args() → Returns 2
     ├─> malloc args array (size 3: 2 args + NULL)
     └─> fill_args() → Copies "echo", "'hello world'" into args
     |
     v
   Result: cmd->args = ["echo", "'hello world'", NULL]
     |
     v
5. execute() → [TODO - Hamza] Needs to:
     - Expand variables based on quote_type
     - Remove quotes after expansion
     - Run the command
     |
     v
6. free_commands() → Frees cmd and args
     |
     v
7. free_tokens() → Frees token list
     |
     v
8. free(input) → Frees "echo 'hello world'" string
     |
     v
   Loop back to readline()


================================================================================
                        QUICK REFERENCE
================================================================================

TOKENIZER FUNCTIONS:
- tokenize()           Main loop, creates token list with quote handling
- is_quote()           Checks if char is ' or " (ASCII 39 or 34)
- extract_quoted_word() Extracts quoted strings with quote_type
- find_closing_quote()  Finds matching quote in string
- is_operator()        Checks if char is |, <, >, etc
- get_token_type()     Maps operator to enum type
- process_operator()   Creates and adds operator token (quote_type=0)
- process_word()       Creates and adds word token (quote_type=0)
- extract_word()       Gets word string from input (stops at quotes)
- new_token()          Allocates token node with quote_type field
- add_token_to_list()  Appends to linked list
- free_tokens()        Cleans up token list

PARSER FUNCTIONS:
- parse()              Main function, creates command structure
- new_command()        Allocates command structure
- count_args()         Counts TOKEN_WORD tokens
- fill_args()          Copies values into args array
- validate_syntax()    Checks for invalid token sequences
- free_commands()      Cleans up command structure

SHELL FUNCTIONS:
- main()               Entry point
- init_shell()         Initialize state
- shell_loop()         Main interactive loop
- process_input()      Pipeline: tokenize→validate→parse→execute
- cleanup_shell()      Final cleanup

QUOTE HANDLING:
- quote_type = 0       No quotes (normal word)
- quote_type = 1       Single quotes (no expansion)
- quote_type = 2       Double quotes (expand variables)
- Quotes preserved     In token->value until after expansion
