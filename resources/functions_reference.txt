================================================================================
                        MINISHELL FUNCTIONS REFERENCE
================================================================================

NOTE: Common functions like printf, malloc, free, etc. are not described here.
      You may not use all of these functions, but this serves as a quick 
      reference guide with links to manual pages.

================================================================================
                            READLINE FUNCTIONS
================================================================================

readline()
    Prototype:    char *readline(const char *prompt);
    Description:  Reads a line from the terminal and returns it using prompt.
                  If no prompt is given, no prompt will be shown.
                  The returned line is allocated with malloc and must be freed.

rl_clear_history()
    Prototype:    void rl_clear_history(void);
    Description:  Clears the history list by deleting all entries.
                  Frees data that readline saves in the history list.

rl_on_new_line()
    Prototype:    int rl_on_new_line(void);
    Description:  Tells the update routine that we've moved to a new empty line.
                  Usually used after outputting a line.

rl_replace_line()
    Description:  No information found for this function.

rl_redisplay()
    Prototype:    int rl_redisplay(void);
    Description:  Changes what's displayed on screen to reflect the current
                  contents of rl_line_buffer.

add_history()
    Prototype:    void add_history(char *s);
    Description:  Saves the line in history so it can be retrieved later
                  (like pressing the up arrow in bash).


================================================================================
                        FILE SYSTEM & DIRECTORY FUNCTIONS
================================================================================

getcwd()
    Header:       #include <unistd.h>
    Prototype:    char *getcwd(char *buf, size_t size);
    Description:  Returns a null-terminated string containing the absolute
                  pathname of the current working directory.
                  The pathname is returned via function result and buf argument.

chdir()
    Header:       #include <unistd.h>
    Prototype:    int chdir(const char *path);
    Description:  Changes the current working directory to the directory
                  specified in path.

stat() & lstat() & fstat()
    Header:       #include <sys/stat.h>
    Prototypes:   int stat(const char *restrict pathname, struct stat *restrict statbuf);
                  int lstat(const char *restrict pathname, struct stat *restrict statbuf);
                  int fstat(int fd, struct stat *statbuf);
    Description:  Return information about a file in the structure pointed to
                  by statbuf.

opendir()
    Header:       #include <sys/types.h>
                  #include <dirent.h>
    Prototype:    DIR *opendir(const char *name);
    Description:  Opens a directory stream corresponding to directory name.
                  Returns a pointer to the directory stream.
                  Stream is positioned at the first entry.

readdir()
    Header:       #include <dirent.h>
    Prototype:    struct dirent *readdir(DIR *dirp);
    Description:  Returns a pointer to a dirent structure representing the next
                  directory entry in the stream pointed to by dirp.
                  Returns NULL on end of stream or error.

closedir()
    Header:       #include <sys/types.h>
                  #include <dirent.h>
    Prototype:    int closedir(DIR *dirp);
    Description:  Closes the directory stream associated with dirp.
                  Also closes the underlying file descriptor.
                  Directory stream descriptor is not available after this call.


================================================================================
                            ERROR HANDLING FUNCTIONS
================================================================================

strerror()
    Header:       #include <string.h>
    Prototype:    char *strerror(int errnum);
    Description:  Returns a pointer to a string describing the error code
                  passed in errnum. String must not be modified by application.

perror()
    Header:       #include <stdio.h>
    Prototype:    void perror(const char *s);
    Description:  Produces a message on standard error describing the last error
                  encountered during a system or library function call.


================================================================================
                            TERMINAL FUNCTIONS
================================================================================

isatty()
    Header:       #include <unistd.h>
    Prototype:    int isatty(int fd);
    Description:  Tests whether fd is a terminal.

ttyname()
    Header:       #include <unistd.h>
    Prototype:    char *ttyname(int fd);
    Description:  Returns a pointer to the null-terminated pathname of the
                  terminal device open on file descriptor fd.
                  Returns NULL on error.

ttyslot()
    Header:       #include <unistd.h>
    Prototype:    int ttyslot(void);
    Description:  Legacy function with historical significance.
                  See manual page for details.

ioctl()
    Header:       #include <sys/ioctl.h>
    Prototype:    int ioctl(int fd, unsigned long request, ...);
    Description:  System call that manipulates the underlying device parameters
                  of special files.

tcsetattr()
    Header:       #include <termios.h>
    Prototype:    int tcsetattr(int fildes, int optional_actions, 
                                const struct termios *termios_p);
    Description:  Sets the parameters associated with the terminal referred to
                  by the open file descriptor fildes from the termios structure.

tcgetattr()
    Header:       #include <termios.h>
    Prototype:    int tcgetattr(int fildes, struct termios *termios_p);
    Description:  Gets the parameters associated with the terminal referred to
                  by fildes and stores them in the termios structure.


================================================================================
                            ENVIRONMENT FUNCTIONS
================================================================================

getenv()
    Header:       #include <stdlib.h>
    Prototype:    char *getenv(const char *name);
    Description:  Searches the environment list for the variable name.
                  Returns a pointer to the corresponding value string.


================================================================================

tgetent() and related functions
    Header:       #include <curses.h>
                  #include <term.h>
    Prototypes:   int tgetent(char *bp, const char *name);
