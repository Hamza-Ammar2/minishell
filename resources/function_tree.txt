================================================================================
                        WHAT HAPPENS ON USER INPUT
================================================================================

SCENARIO 1: Normal Input
────────────────────────

    User types: "hello world" + ENTER
         │
         ├─> readline() allocates: char *input = "hello world"
         │
         ├─> add_history("hello world")
         │   └─> readline stores internal copy for history
         │
         ├─> printf("You typed: hello world\n")
         │
         └─> free(input)
             └─> Our allocated string freed
             └─> History copy still exists (freed in cleanup_shell)


SCENARIO 2: Empty Input
────────────────────────

    User presses: ENTER (empty line)
         │
         ├─> readline() returns: char *input = ""
         │
         ├─> if (*input) → FALSE (first char is '\0')
         │   └─> Skip add_history() and printf()
         │
         └─> free(input)
             └─> Free the empty string


SCENARIO 3: Ctrl+D (EOF)
────────────────────────

    User presses: Ctrl+D
         │
         ├─> readline() returns: NULL
         │
         ├─> if (!input) → TRUE
         │   ├─> printf("exit\n")
         │   └─> break;
         │
         └─> EXIT LOOP → cleanup_shell() → return to shell


================================================================================
                        CURRENT LIMITATIONS
================================================================================

✗ Commands are NOT executed (only echoed back)
✗ No parsing (doesn't split into arguments)
✗ No pipes, redirections, or special characters
✗ No built-in commands (cd, echo, etc.)
✗ No environment variable handling
✗ No signal handling (Ctrl+C will kill the program)
✗ No process management (fork, exec, wait)
