1. Update t_command struct in minishell.h:
-------------------------------------------
   Current:
   ```c
   typedef struct s_command
   {
       char    **args;
   }   t_command;
   ```

   Updated:
   ```c
   typedef struct s_command
   {
       char                **args;           // Command and arguments
       t_token             *redirects;       // List of redirect tokens (operator + filename pairs)
       struct s_command    *next;            // Next command in pipeline
   }   t_command;
   ```
   
   IMPORTANT: The redirects list contains MERGED tokens:
   - Each token combines the operator TYPE with the filename VALUE
   - token->type = redirect operator (TOKEN_REDIRECT_IN, TOKEN_REDIRECT_OUT, etc.)
   - token->value = filename string
   - Example: For "cat < input.txt > output.txt"
     redirects → [TOKEN_REDIRECT_IN, "input.txt"] → [TOKEN_REDIRECT_OUT, "output.txt"] → NULL
   
   These are NEW tokens created by merging operator type + filename value,
   NOT copies of the original tokens!
