1. count_pipes()

   Signature: int count_pipes(t_token *tokens);
   Returns: Number of pipe tokens found
   Example: "ls | grep test | wc" → returns 2
   
   Logic:
   - Traverse token list
   - Count TOKEN_PIPE tokens
   - Return count

2. find_next_pipe()
   Purpose: Find next pipe token in list
   Signature: t_token *find_next_pipe(t_token *tokens);
   Returns: Pointer to first pipe token, or NULL if none
   Example: [ls]→[-l]→[|]→[grep] → returns pointer to [|]
   
   Logic:
   - Traverse until TOKEN_PIPE found or end of list
   - Return pointer to pipe token or NULL

3. count_command_args()
   Purpose: Count arguments before next pipe or end
   Signature: int count_command_args(t_token *tokens);
   Returns: Number of words before pipe/end
   Example: [ls]→[-l]→[|]→[grep] → returns 2 (ls, -l)
   
   Logic:
   - Count TOKEN_WORD tokens
   - Stop at TOKEN_PIPE or redirection or end
   - Return count

4. extract_command_tokens()
   Purpose: Extract tokens for one command (until pipe)
   Signature: t_token *extract_command_tokens(t_token **tokens);
   Returns: New token list for one command
   Modifies: Advances *tokens to after pipe
   Example: [ls]→[-l]→[|]→[grep]→[test]
            Returns: [ls]→[-l]
            Updates tokens to point to: [grep]→[test]
   
   Logic:
   - Create new token list
   - Copy tokens until pipe or end
   - Advance original pointer
   - Return new list

5. parse_pipeline()
   Purpose: Parse full pipeline into command linked list
   Signature: t_command *parse_pipeline(t_token *tokens);
   Returns: Head of command linked list
   Example: "ls -l | grep test" → cmd1→cmd2→NULL
   
   Logic:
   - Count pipes to know number of commands
   - For each command segment:
     * Extract tokens until pipe
     * Parse single command
     * Link to previous command
   - Return head of list

6. find_redirections()
   Purpose: Count redirection operators in token list
   Signature: int find_redirections(t_token *tokens);
   Returns: Number of redirection operators found
   Example: [cat]→[<]→[file]→[>]→[out] → returns 2
   
   Logic:
   - Traverse token list
   - Count TOKEN_REDIRECT_IN, TOKEN_REDIRECT_OUT, TOKEN_REDIRECT_APPEND, TOKEN_REDIRECT_HEREDOC
   - Return count

7. extract_redirections()
   Purpose: Extract redirect tokens into separate list
   Signature: t_token *extract_redirections(t_token **tokens);
   Returns: New token list with ONLY redirect operator+filename pairs
   Modifies: Removes redirect tokens from original list
   Example: Input:  [cat]→[<]→[in.txt]→[-n]→[>]→[out.txt]
            Returns: [<]→[in.txt]→[>]→[out.txt]→NULL
            Updates tokens to: [cat]→[-n]→NULL
   
   Logic:
   - Create new empty list for redirects
   - Traverse original token list
   - When you hit redirect operator:
     * Copy operator token to redirect list
     * Copy next token (filename) to redirect list
     * Remove both from original list
   - Return redirect list

8. copy_token()
   Purpose: Duplicate a single token
   Signature: t_token *copy_token(t_token *token);
   Returns: New token with copied values
   Example: Copies token structure and duplicates the value string
   
   Logic:
   - Allocate new token
   - Copy type and quote_type
   - Duplicate value string with strdup
   - Set next to NULL
   - Return new token

9. remove_token_after()
   Purpose: Remove a specific token from linked list
   Signature: void remove_token_after(t_token *prev);
   Modifies: Removes the token after prev from list
   Example: [cat]→[<]→[file]→[-n]
            Call remove_token_after(cat)
            Result: [cat]→[file]→[-n]
   
   Logic:
   - Save prev->next
   - Set prev->next = prev->next->next
   - Free removed token's value and structure

10. parse_redirections()
    Purpose: Parse redirection tokens and attach to command
    Signature: void parse_redirections(t_command *cmd, t_token **tokens);
    Returns: void (modifies cmd structure)
    Modifies: Sets cmd->redirects field, removes redirect tokens from original list
    Example: [cat]→[<]→[in]→[>]→[out]→[-n]
             Sets: cmd->redirects → [<]→[in]→[>]→[out]→NULL
             Updates tokens to: [cat]→[-n]→NULL
    
    Logic:
    - Call extract_redirections() to get redirect token list
    - Store result in cmd->redirects
    - Original token list now only has command words

11. validate_pipe_syntax()
    Purpose: Check for valid pipe usage
    Signature: int validate_pipe_syntax(t_token *tokens);
    Returns: 1 if valid, 0 if error
    Checks:
    - No pipe at start: "| ls" → ERROR
    - No pipe at end: "ls |" → ERROR
    - No double pipes: "ls || grep" → ERROR
    - Token before and after each pipe
    
    Logic:
    - Check first token is not pipe
    - Check last token is not pipe
    - For each pipe, verify tokens before and after
    - Return 1 if all checks pass

12. validate_redirection_syntax()
    Purpose: Check redirections have filenames
    Signature: int validate_redirection_syntax(t_token *tokens);
    Returns: 1 if valid, 0 if error
    Checks:
    - Every < has filename after: "cat <" → ERROR
    - Every > has filename after: "ls >" → ERROR
    - Every >> has filename after
    - Every << has delimiter after
    
    Logic:
    - For each redirection token:
      * Check next token exists
      * Check next token is WORD type
    - Return 1 if all checks pass
