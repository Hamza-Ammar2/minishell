------------------
Location: src/lexer/tokenizer.c

Purpose:
    Check if a character is a quote character (' or ")

Prototype:
    int is_quote(char c)

Parameters:
    c - character to check

Return:
    1 if c is ' or "
    0 otherwise

Logic:
    return (c == '\'' || c == '"');


================================================================================
                        STEP 3: FIND CLOSING QUOTE
================================================================================

FUNCTION: find_closing_quote
-----------------------------
Location: src/lexer/tokenizer.c

Purpose:
    Find the position of the matching closing quote in a string

Prototype:
    int find_closing_quote(const char *str, char quote)

Parameters:
    str   - string to search (starting AFTER the opening quote)
    quote - the quote character to match (' or ")

Return:
    Index of the closing quote
    -1 if no closing quote found (syntax error)

Logic:
    1. Loop through str character by character
    2. If you find the matching quote character, return the index
    3. If you reach the end (\0) without finding it, return -1

Example:
    Input:  str = "hello world' more text", quote = '\''
    Output: 11 (position of the closing ')

Notes:
    - Don't worry about escaped quotes for now (bonus feature)
    - Single quotes: NOTHING is special inside, not even backslash
    - Double quotes: Same for now (expansion happens later)


================================================================================
                        STEP 4: EXTRACT QUOTED STRING
================================================================================

FUNCTION: extract_quoted_word
------------------------------
Location: src/lexer/tokenizer.c

Purpose:
    Extract a quoted string from input, INCLUDING the quote characters
    Store the quote type for later processing

Prototype:
    char *extract_quoted_word(const char *input, int *i, int *quote_type)

Parameters:
    input      - the full input string
    i          - pointer to current position (will be updated)
    quote_type - pointer to store quote type (1 or 2)

Return:
    Allocated string containing the quoted text WITH quotes
    NULL on error (unclosed quote or malloc failure)

Logic:
    1. Remember the opening quote character (input[*i])
    2. Set *quote_type based on quote character:
         - 1 if single quote
         - 2 if double quote
    3. Find the closing quote using find_closing_quote()
    4. If no closing quote found:
         - Print error: "minishell: syntax error: unclosed quote"
         - Return NULL
    5. Calculate length: from opening quote to closing quote (inclusive)
    6. Allocate memory for the string
    7. Copy the substring (INCLUDING both quotes)
    8. Update *i to position AFTER the closing quote
    9. Return the allocated string

Example:
    Input:  input = "echo 'hello world' done", *i = 5 (pointing at ')
    Output: "'hello world'" (with quotes)
            *i = 18 (pointing at space before 'done')
            *quote_type = 1

Error Handling:
    - If find_closing_quote returns -1: unclosed quote error
    - If malloc fails: return NULL
    - Caller should handle NULL return and stop tokenizing

================================================================================
                        NOTES & TIPS
================================================================================

Memory Management:
    - extract_quoted_word() allocates memory → caller must free
    - Existing free_tokens() should handle this (it frees token->value)
    - No changes needed to cleanup code

Quote Removal:
    - DON'T remove quotes in the tokenizer
    - Keep them in token->value: "'hello world'" not "hello world"
    - They'll be removed later (after expansion, Person B's job)
    - The quote_type field tells you they were quoted

Why Keep Quotes:
    - Makes debugging easier (you can see what was quoted)
    - Expansion needs to happen before quote removal
    - Quote removal is a simple string processing step at the end

Testing Strategy:
    - Test each function individually first
    - Use printf to debug: print each token with its quote_type
    - Compare with bash: echo 'hello' "world"
    - Test errors: unclosed quotes should print error and return NULL

Common Bugs:
    - Off-by-one errors with closing quote position
    - Forgetting to update *i pointer
    - Not including quotes in the extracted string
    - Memory leaks (not freeing on error paths)
