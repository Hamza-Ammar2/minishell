MINISHELL STRUCT RECOMMENDATIONS
=================================

1. TOKEN STRUCTURE
------------------
typedef struct s_token
{
    char            *value;         // The actual token string
    int             type;           // Token type (WORD, PIPE, REDIR_IN, REDIR_OUT, etc.)
    struct s_token  *next;          // Next token in the list
}   t_token;

Token types enum:
typedef enum e_token_type
{
    TOKEN_WORD,         // Regular word/command
    TOKEN_PIPE,         // |
    TOKEN_REDIR_IN,     // <
    TOKEN_REDIR_OUT,    // >
    TOKEN_APPEND,       // >>
    TOKEN_HEREDOC,      // <<
    TOKEN_ENV_VAR,      // $VAR
    TOKEN_SQUOTE,       // Single quote content
    TOKEN_DQUOTE        // Double quote content
}   t_token_type;


2. COMMAND STRUCTURE
--------------------
typedef struct s_cmd
{
    char            **args;         // Command arguments (NULL-terminated array)
    char            *cmd_path;      // Full path to executable
    int             infile;         // Input file descriptor
    int             outfile;        // Output file descriptor
    struct s_cmd    *next;          // Next command in pipeline
}   t_cmd;


3. REDIRECTION STRUCTURE
------------------------
typedef struct s_redir
{
    int             type;           // Type of redirection (IN, OUT, APPEND, HEREDOC)
    char            *file;          // Filename for redirection
    int             fd;             // File descriptor
    struct s_redir  *next;          // Next redirection
}   t_redir;


4. ENVIRONMENT VARIABLE STRUCTURE
----------------------------------
typedef struct s_env
{
    char            *key;           // Variable name
    char            *value;         // Variable value
    struct s_env    *next;          // Next environment variable
}   t_env;


5. MAIN SHELL STRUCTURE
-----------------------
typedef struct s_shell
{
    char            *input;         // Current input line
    t_token         *tokens;        // Tokenized input
    t_cmd           *cmds;          // Parsed commands
    t_env           *env;           // Environment variables list
    char            **envp;         // Environment array for execve
    int             exit_status;    // Last command exit status
    int             stdin_backup;   // Backup of original stdin
    int             stdout_backup;  // Backup of original stdout
    pid_t           *pids;          // Array of child process IDs
    int             num_cmds;       // Number of commands in pipeline
}   t_shell;


6. PARSER STRUCTURE (Optional)
-------------------------------
typedef struct s_parser
{
    t_token         *current;       // Current token being parsed
    t_cmd           *cmd_list;      // List of parsed commands
    int             error;          // Parse error flag
}   t_parser;


7. HEREDOC STRUCTURE
--------------------
typedef struct s_heredoc
{
    char            *delimiter;     // Heredoc delimiter
    char            *content;       // Heredoc content
    int             fd;             // Temporary file descriptor
    struct s_heredoc *next;         // Next heredoc
}   t_heredoc;


RECOMMENDED ORGANIZATION
========================

Main header file (minishell.h) should include:
- All struct definitions
- Function prototypes organized by module:
  * Lexer/Tokenizer functions
  * Parser functions
  * Executor functions
  * Built-in functions
  * Environment variable functions
  * Redirection functions
  * Signal handling functions
  * Utility functions
  * Memory management functions

Additional considerations:
- Use typedef for cleaner code
- Keep structures simple and focused
- Use linked lists for dynamic-size data
- Store file descriptors for proper cleanup
- Maintain exit status for $? expansion
- Backup stdin/stdout for restoring after execution
